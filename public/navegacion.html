🧭 Navegación del Front Controller

Prueba las diferentes rutas del sistema

📋 Instrucciones:

Haz clic en los enlaces para probar las diferentes funcionalidades del Front Controller con sistema de layouts.

📄 Páginas Principales

🏠 Página de Inicio
Muestra la página principal con hero section y características
URL: index.php?route=home
ℹ️ Acerca de
Muestra información de la empresa, misión y valores
URL: index.php?route=about
📞 Contacto
Muestra formulario de contacto e información de la empresa
URL: index.php?route=contact

❌ Páginas de Error

🚫 Error 404
Página de error 404 (página no encontrada)
URL: index.php?route=404
🔍 Ruta Inexistente
Prueba una ruta que no existe (debería mostrar error 404)
URL: index.php?route=inexistente

🔧 Páginas Implementadas

⚙️ Servicios
Página de servicios con catálogo completo y testimonios
URL: index.php?route=services
🛒 Productos
Página de productos con precios y características
URL: index.php?route=products
📝 Blog
Página del blog con artículos y categorías
URL: index.php?route=blog

💡 ¿Qué deberías ver?

  • Páginas normales: Contenido completo con navegación y footer
  • Error 404: Página de error personalizada con variables correctas
  • Rutas inexistentes: Deberían mostrar error 404 automáticamente
  • Sin errores de JavaScript: No deberían aparecer errores en la consola

🔍 Debug: Si ves warnings de variables no definidas, significa que hay un problema en el sistema de layouts.
