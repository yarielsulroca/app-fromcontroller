# 🏗️ Arquitectura en Capas - Guía de Implementación

## 📋 Resumen del Proyecto
Este proyecto implementa una **arquitectura en capas** en PHP con separación clara de responsabilidades, conexión a MySQL y patrones de diseño modernos.

## 🎯 Características Principales
- ✅ **Arquitectura en Capas** - Separación clara de responsabilidades
- ✅ **Conexión MySQL** - Base de datos con timestamps y soft delete
- ✅ **Patrón Singleton** - Para conexión de base de datos
- ✅ **Modelos CRUD** - Operaciones básicas y avanzadas
- ✅ **Sistema de Layouts** - Plantillas reutilizables
- ✅ **Front Controller** - Punto de entrada único

## 🎯 Componentes por Capa

### **1. Capa de Configuración**
- **database.php**: Configuración MySQL (host, database, username, password)
- **app.php**: Configuración general (nombre, versión, debug, timezone)

### **2. Capa de Base de Datos**
- **Database.php**: Clase singleton para conexión MySQL
- **BaseModel.php**: Modelo base con métodos CRUD comunes y timestamps

### **3. Capa de Modelos (Entidades)**
- **User.php**: Gestión de usuarios (autenticación, roles, encriptación)
- **Product.php**: Gestión de productos (catálogo, stock, categorías)
- **Service.php**: Gestión de servicios (duración, precios, categorías)
- **BlogPost.php**: Gestión de posts (estados, autores, búsquedas)

### **4. Capa de Controladores**
- Integración con modelos
- Validación de datos
- Manejo de errores mejorado
- Lógica de negocio

#### **Controladores de Páginas (Públicas):**
- **HomeController.php**: Dashboard principal con estadísticas dinámicas
- **AboutController.php**: Página "Acerca de" con información de la empresa
- **ContactController.php**: Página de contacto con formulario y validación

#### **Controladores de Gestión (Admin):**
- **UserController.php**: CRUD completo de usuarios (crear, editar, eliminar)
- **ProductController.php**: CRUD completo de productos (catálogo, stock)
- **ServiceController.php**: CRUD completo de servicios (duración, precios)
- **BlogController.php**: CRUD completo de posts (estados, autores)

#### **Controladores de Sistema:**
- **ErrorController.php**: Manejo de errores 404, 500 y otros


### **5. Capa de Vistas**
- **Vistas Públicas**: home.php, about.php, contact.php, services.php, products.php, blog.php
- **Vistas de Detalle**: services/detail.php, products/detail.php, blog/post.php
- **Vistas de Administración**: admin/users/, admin/products/, admin/services/, admin/blog/
- **Formularios**: create.php, edit.php con validación
- **Listados**: index.php con paginación y filtros
- **Templates**: layouts/main.php reutilizable

## 🚨 Errores Comunes y Soluciones

### **Error: "Class not found"**
- Verificar que el archivo del modelo existe
- Verificar que la clase tiene el nombre correcto
- Verificar que el require_once está correcto

### **Error: "Database connection failed"**
- Verificar configuración en config/database.php
- Verificar que MySQL está corriendo
- Verificar credenciales de acceso

### **Error: "Table doesn't exist"**
- Ejecutar database/schema.sql
- Verificar nombre de la base de datos
- Verificar que las tablas se crearon correctamente
